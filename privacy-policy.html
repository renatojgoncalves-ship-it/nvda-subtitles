Política de Privacidade
Leitor de Legendas para NVDA

Última atualização: junho de 2026

1. O que esta extensão faz

A extensão Leitor de Legendas para NVDA lê automaticamente as legendas de Netflix, Disney+ e Amazon Prime Video em voz alta através do leitor de ecrã NVDA, utilizando regiões ARIA live. O seu único propósito é melhorar a acessibilidade para pessoas com deficiência visual ou auditiva.

2. Dados lidos

Para cumprir o seu propósito, a extensão lê o texto das legendas presentes no DOM (estrutura da página) dos sites acima indicados enquanto o utilizador os visita. Estes dados são utilizados exclusivamente para os anunciar ao NVDA através de uma região ARIA live na mesma página.

3. O que NÃO fazemos com esses dados

  • Não transmitimos qualquer dado para servidores externos.
  • Não armazenamos nem registamos o texto das legendas.
  • Não partilhamos dados com terceiros.
  • Não utilizamos os dados para publicidade, análise ou qualquer fim diferente da leitura em voz alta via NVDA.
  • Não recolhemos dados de identificação pessoal (nome, e-mail, IP, etc.).

4. Processamento local

Todo o processamento ocorre inteiramente no dispositivo do utilizador. A extensão não contém código remoto, não faz chamadas de rede e não requer qualquer conta ou autenticação.

5. Permissões utilizadas

A extensão injeta um content script nas páginas de Netflix, Disney+ e Amazon Prime Video exclusivamente para detetar e ler o texto das legendas. Não são solicitadas permissões para aceder a outros dados do navegador (histórico, cookies, palavras-passe, etc.).
